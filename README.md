🎓 SmartExam: AI-Powered Proctoring & Automated Paper ParserSmartExam is a secure, full-stack online examination portal designed to bridge the gap between traditional paper-based testing and digital assessment. Built specifically with the needs of university environments like VSSUT in mind, it automates the transition from PDF question papers to interactive, proctored digital exams.🚀 Key Features🤖 AI-Powered Question Paper ParserAutomated Digitization: Teachers can upload standard subjective PDF question papers (e.g., VSSUT Mid-Sem/End-Sem formats).Regex-Based Extraction: The system uses advanced Regular Expressions to identify question headers ($Q1, Q2$), sub-parts ($a, b, A, B$), and nested marks.Dynamic Weightage: Automatically detects marks written in brackets, such as $[2 \times 3]$ or $[8]$, and maps them to the database.Teacher Review Layer: A verification dashboard allows teachers to edit AI-extracted text and set correct answer keys before publishing.🛡️ Secure Lockdown ProctoringTab-Switch Detection: Real-time monitoring tracks if a student switches tabs or minimizes the browser.Security Audit Report: Generates a detailed "Cheating Log" for teachers, showing exact timestamps of suspicious activity.Fullscreen Enforcement: Ensures students remain within the exam environment throughout the duration.📊 Comprehensive Grading SystemHybrid Evaluation: Supports both auto-graded MCQs and teacher-reviewed subjective/long-answer questions.Weightage Logic: Final scores are calculated based on individual question marks rather than a simple 1-point system.Result Publishing: Secure release of grades to student dashboards once evaluation is finalized.🛠️ Tech StackBackend: Python (Flask).Database: SQLite with SQLAlchemy ORM.Security: Flask-Bcrypt (Hashing), Flask-Talisman (Production Security), Flask-Login.File Processing: PyPDF2 (PDF Text Extraction).Frontend: HTML5, CSS3 (Bootstrap 5), JavaScript.Deployment: Gunicorn (WSGI Server) for Render/Cloud environments.📂 Project StructurePlaintext├── app.py              # Main application logic & routes

🌐 Deployment GuideThis project is optimized for deployment on Render or Railway:Gunicorn: The Procfile is pre-configured: web: gunicorn app:app.Security: Flask-Talisman is integrated to force HTTPS and set secure headers in production.Database: The app automatically handles db.create_all() and seeds a default Admin user (admin@vssut.ac.in) upon its first run on the server.📝 Future ScopeAI Answer Verification: Integrating LLM APIs to provide automated "similarity scores" for subjective answers.Live Webcam Monitoring: Adding periodic snapshots to verify student identity.Complex Math Support: Better parsing for complex LaTeX formulas like the CRC8 polynomial $x^5+x^3+x+1$.
